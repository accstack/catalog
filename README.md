# Word Stress Catalog (gated preview)

This repository serves a password-protected preview of the Word Stress Catalog at
https://mattschwartzscience.github.io/word-stress-catalog/ — the page is encrypted client-side; the password is
sent by email to invited readers. Nothing readable is stored in this repository.

Maintainer: Matthew D. Schwartz (Harvard). Corrections and takedown requests: open an issue.
