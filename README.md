# Word Stress Catalog (gated preview)

This repository serves a password-protected preview of the Word Stress Catalog at
https://mattschwartzscience.github.io/word-stress-catalog/ — the page is encrypted client-side; the password is
sent by email to invited readers. The catalog itself is not stored here in readable form.

The `clips/` folder holds short audio excerpts (one per language, a few seconds each) from openly licensed speech
collections, so that readers can hear the languages; `clips/ATTRIBUTION.md` lists the source, item, licence and
attribution of every excerpt. Those files carry their original licences, not this repository's.

Maintainer: Matthew D. Schwartz (Harvard). Corrections and takedown requests: open an issue.
